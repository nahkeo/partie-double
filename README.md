# Partie Double

Application web pour apprendre la comptabilité française, du premier bilan à la consolidation : 23 modules, 129 exercices corrigés, révision des points faibles, cartes mémoire, examens blancs et certificats.

En ligne : https://compta.nahkeo.fr/

L'application tient dans des fichiers statiques (`index.html`, `data.js`, `app.js`, `plus.js`) et s'installe sur téléphone comme une application (`manifest.webmanifest`, `sw.js`). La progression est enregistrée dans le navigateur de chaque appareil.

Les vidéos proposées dans les leçons viennent de la playlist YouTube « Les Meilleurs Cours de Comptabilité » de la chaîne Les Geeks des Chiffres.
